## Parte 2: Navegación real con React Router

> 🆕 **Esto es contenido nuevo, no una corrección.** Lo que armamos hasta el paso 55 usa un Navbar de react-bootstrap con anchors (`#productos`, `#carrito`) — eso solo salta dentro de la misma página. Acá agregamos **React Router**, que sí cambia de vista sin recargar la página y actualiza la URL.
>
> **Dónde partir:** desde el paso 56 en adelante, asumiendo que ya tienes la app del tutorial anterior corriendo (pasos 1–55). Si vienes de cero, primero completa esa parte.

56. En la terminal integrada de VS Code, instala React Router:
```bash
    npm install react-router-dom
```

57. Abre `src/main.jsx` en VS Code y reemplaza todo por:
```jsx
    import { StrictMode } from 'react'
    import { createRoot } from 'react-dom/client'
    import { BrowserRouter } from 'react-router-dom'
    import 'bootstrap/dist/css/bootstrap.min.css'
    import App from './App.jsx'

    createRoot(document.getElementById('root')).render(
      <StrictMode>
        <BrowserRouter>
          <App />
        </BrowserRouter>
      </StrictMode>,
    )
```
    Guarda con `Ctrl+S` / `Cmd+S`.

    > `BrowserRouter` es quien le da a toda la app la capacidad de cambiar de vista según la URL. Tiene que envolver a `App`, no ir dentro de él.

58. Abre `src/App.jsx` y reemplaza todo por:
```jsx
    import { Routes, Route } from 'react-router-dom'
    import { Container } from 'react-bootstrap'
    import Navigation from './components/Navbar'
    import ProductList from './components/ProductList'
    import ShoppingCart from './components/ShoppingCart'
    import RegistrationForm from './components/RegistrationForm'

    function App() {
      return (
        <div className="App">
          <Navigation />
          <Container>
            <Routes>
              <Route path="/" element={<ProductList />} />
              <Route path="/carrito" element={<ShoppingCart />} />
              <Route path="/registro" element={<RegistrationForm />} />
            </Routes>
          </Container>
        </div>
      )
    }

    export default App
```
    Guarda con `Ctrl+S` / `Cmd+S`.

    > ⚠️ Ojo con el cambio de estructura: antes `App.jsx` mostraba los 3 componentes **al mismo tiempo**, uno debajo del otro (`Row`/`Col`). Ahora cada componente es una **vista separada**: solo se muestra uno a la vez, según la URL. Por eso también sacamos `Row` y `Col` de acá — ya no hace falta ese layout de 3 columnas.

59. Abre `src/components/Navbar.jsx` y reemplaza todo por:
```jsx
    import { Navbar, Nav, Container } from 'react-bootstrap'
    import { Link } from 'react-router-dom'

    const Navigation = () => {
      return (
        <Navbar bg="light" expand="lg">
          <Container>
            <Navbar.Brand as={Link} to="/">Mi Tienda</Navbar.Brand>
            <Navbar.Toggle aria-controls="basic-navbar-nav" />
            <Navbar.Collapse id="basic-navbar-nav">
              <Nav className="me-auto">
                <Nav.Link as={Link} to="/">Productos</Nav.Link>
                <Nav.Link as={Link} to="/carrito">Carrito</Nav.Link>
                <Nav.Link as={Link} to="/registro">Registro</Nav.Link>
              </Nav>
            </Navbar.Collapse>
          </Container>
        </Navbar>
      )
    }

    export default Navigation
```
    Guarda con `Ctrl+S` / `Cmd+S`.

    > Este es el cambio clave: `as={Link} to="/carrito"` le dice a react-bootstrap que en vez de renderizar un `<a href="#carrito">` normal (que solo salta dentro de la página), renderice el `Link` de React Router (que cambia de vista sin recargar). El estilo de Bootstrap se mantiene igual — solo cambia qué pasa al hacer clic.

✅ **Checkpoint:** con `npm run dev` corriendo (si no está, `npm run dev` de nuevo), entra a `http://TU-IP-PUBLICA:3000`. Haz clic en "Carrito" — la URL cambia a `.../carrito` y la página **no** recarga (no parpadea). Haz clic en "Registro" — mismo efecto. Haz clic en "Mi Tienda" — vuelves a Productos.

60. Prueba refrescar el navegador (F5) estando en `/carrito`. Debería seguir mostrando el carrito.

    > ⚠️ **Si hiciste la Parte opcional de Nginx:** al probar esto en producción (Nginx), refrescar en `/carrito` va a dar **404**, porque Nginx busca un archivo `carrito` que no existe — todo el ruteo lo maneja React en el navegador, no el servidor. La solución es agregar un "fallback" en la configuración de Nginx:
    > ```bash
    > sudo nano /etc/nginx/sites-available/default
    > ```
    > Dentro del bloque `location / {`, cambia la línea `try_files $uri $uri/ =404;` por:
    > ```
    > try_files $uri $uri/ /index.html;
    > ```
    > Guarda, y reinicia Nginx: `sudo systemctl restart nginx`
